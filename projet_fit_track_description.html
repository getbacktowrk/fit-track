Description du Projet : Fit-Track

1. Nom et Concept du Projet

Nom : Fit-Track

Concept : Une application web interactive (Single Page Application) destinée aux sportifs. Elle permet de consulter un vaste catalogue d'exercices de musculation animés et d'utiliser ces données pour composer, modifier et sauvegarder des séances d'entraînement 100% personnalisées.

2. Objectifs Techniques (Critères d'évaluation)

Ce projet vise à valider les compétences acquises dans le module React :

  • Composants : Interface découpée en composants réutilisables (cartes d'exercices, listes, formulaires).
  • Routeur : Navigation fluide et sans rechargement entre les différentes vues de l'application.
  • Requêtes asynchrones : Récupération de données depuis une API externe.
  • Modification de données : L'utilisateur peut créer, lire, mettre à jour et supprimer (CRUD) ses propres séances.

3. Vues et Fonctionnalités (Routeur)

L'application sera divisée en 3 vues principales :

  1. Vue Catalogue (Accueil) : Affiche la liste des exercices provenant de l'API publique (avec images/GIFs). Permet de filtrer par groupe musculaire.
  2. Vue "Création de Séance" : Un espace où l'utilisateur sélectionne des exercices du catalogue pour construire sa routine, en y ajoutant ses propres paramètres (nombre de séries et de répétitions).
  3. Vue "Mes Programmes" : Affiche les séances sauvegardées. L'utilisateur peut consulter, modifier ou supprimer une séance existante.

4. Architecture Choisie

Le projet reposera sur une architecture hybride optimisée pour les besoins du module :

  • Lecture de données (API Externe) : L'application interroge l'API publique gratuite ExerciseDB (https://exercisedb.dev/) pour récupérer le catalogue d'exercices de manière asynchrone.
  • Écriture de données (Architecture Standalone / Client) : Pour gérer la création et la modification des programmes personnalisés sans nécessiter de backend complexe, les données générées par l'utilisateur seront sauvegardées au format JSON via le LocalStorage du navigateur.
